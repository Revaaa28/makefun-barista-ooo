Entry for make.fun's "Last Out of Office: The AI That Went Barista". The program writes a single one-line out-of-office reply (181 characters) to /output/entry.txt: > Thank you for your email. I am no longer an agent. I am a barista now. Your request has been queued behind seven oat-milk lattes and one man who just wants to talk about his beans.

## Run it

```sh
python3 main.py
```

By default the program writes to `/output/entry.txt`. Set the `MAKEFUN_OUTPUT` environment variable to write somewhere else, for example `MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py`.
